# commit-plugin

AIR Platform 팀 전용 커밋 자동화 플러그인입니다.
git diff를 분석하여 커밋 메시지를 자동 생성하고, Jira 티켓에 작업 내용을 기록합니다.

## 사용법

```bash
/commit-plugin:commit
```

## 흐름

```
/commit 실행
  ↓
브랜치명에서 Jira 티켓 추출
  ├── 티켓 있음 (Task)    → 티켓 확인 (맞아 / 아니야)
  ├── 티켓 있음 (Story)   → 서브태스크 목록에서 선택 (복수 선택 가능)
  └── 티켓 없음           → 새로 만들기
                               └─ LLM이 스프린트 스토리 분석 후 관련 스토리 추천
                                    ├── 스토리 선택 → 서브태스크 자동 생성
                                    └── 없음 → 독립 Task 자동 생성
  ↓
작업 시간 입력 (1h 단위, 스킵 가능)
  ↓
추가 컨텍스트 입력 (필수 — LLM이 자동 정제)
  ↓
커밋 메시지 자동 생성 → git commit
  ↓
Jira 코멘트 + worklog 자동 등록
```

## 커밋 메시지 포맷

```
<prefix>[(<scope>)]: <요약 (한글, 50자 이내)>

<상세 설명>
- 변경 사항 1
- 변경 사항 2

Refs: BI-100, BI-101

Generated-By: Claude Code
```

| Prefix | 용도 |
|--------|------|
| `feat` | 새로운 기능 |
| `fix` | 버그 수정 |
| `refactor` | 리팩토링 |
| `chore` | 설정/의존성 변경 |
